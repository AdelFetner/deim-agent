When an event is cancelled we refund a percentage of every settled payment.

- New `RefundGatewayClient` calling the provider's `/v1/refunds` endpoint.
- New `RefundService.refundBatch(ids, percentage)`; skips non-settled payments,
  marks a payment `REFUNDED` once the refunded total reaches the amount.
- `PaymentRepository.recordRefund` persists the new refunded total and status.

Tested against the gateway sandbox with a 50% refund on 3 payments.
