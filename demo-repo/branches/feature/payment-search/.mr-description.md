Back-office operators need to find payments by a fragment of the payer id.

- `PaymentRepository.searchByPayer` + `countByPayer` (case-insensitive LIKE).
- `PaymentService.searchByPayer` returns a `SearchResult` with items, current page and total pages,
  using the 1-based page number the UI pager sends.
